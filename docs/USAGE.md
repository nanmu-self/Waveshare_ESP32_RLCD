# 希娜 Syna 使用说明

适用于微雪 **ESP32-S3-RLCD-4.2**（400×300 黑白圆屏，16 MB Flash / 8 MB PSRAM）+ 配套电脑端 **Syna Reporter**。当前版本：1.0.0。

> 硬件型号唯一：本固件只适配 esp32-s3-rlcd-4.2，不要刷到其他型号。

---

## 一、设备是什么

开发板是一个桌面小助手，通过局域网从电脑端 Reporter 采集只读数据并在屏幕上展示：

- **首页**：时间、温湿度、AI Agent 状态（工作中 / 空闲 / 已完成 / 离线）、额度网格（5h / 周 / 月条形图 + 过期倒计时 + 套餐来源 + 剩余百分比）、右侧**日历卡片**。
- **性能页**：CPU / GPU / 内存 / 磁盘占用、温度、实时网速曲线。
- **Syna 页**：语音对话、待办、API 余额。
- **天气页**：和风天气实况与 3 天预报、农历、空气质量、紫外线、风向、室内温湿度。
- **电脑列表**：发现并绑定局域网内同一账号的电脑。
- **关于页**：版本、作者、设备 IP（联网后附带"管理页 ：8080"提示）。

数据的采集范围是**只读**的：只统计使用率、温度、状态标记等摘要，不读取提示词、代码、文件内容、API Key，也不抓登录态。

## 二、快速开始

1. **安装电脑端**：打开 `SynaInstaller-1.0.0.exe`。
   - 只需要电脑端数据 → 选“仅安装 Reporter”；
   - 板子已有本项目固件 → 选“保留配置升级”（自动备份、只写应用分区，保留 Wi-Fi 与电脑绑定）；
   - “首次安装”会**清除开发板原有数据**，操作前确认。
2. **联网**：板子与电脑连入**同一个允许设备互访的 Wi-Fi**（或手机热点）。Reporter 只在"专用网络"开放 UDP 8765 入站，Windows 防火墙弹窗时只允许"专用网络"。
3. **绑定**：板子首次发现 Reporter 时自动保存配对指纹，无需手动复制令牌。绑定后首页即出现性能与额度数据。

PC 上可打开 `http://127.0.0.1:8765/api/v1/health` 验证 Reporter 是否在运行。

## 三、按键操作

| 操作 | 功能 |
| --- | --- |
| KEY **短按** | 在 首页 → 性能 → Syna → 天气 → 关于 五个页面间循环 |
| KEY **长按** | 打开电脑列表，选择并绑定当前电脑 |
| **BOOT 长按** | 打开设置门户（见下节） |

## 四、设置门户（"召唤Syna-sama"页）

需要配置天气 Key、额度来源等设置时：

1. **BOOT 键长按** → 板子发出热点 `Syna-0721`；
2. 电脑连接该热点，浏览器访问 `http://192.168.4.1`；
3. 在页面内可设置：Wi-Fi 凭证、**和风天气 API Key**（存板端 NVS，不入仓库）、**额度数据源**等。

屏幕上不显示任何 IP；热点入口保持免密，作为忘记密码后的恢复通道。

## 五、局域网管理页（板子联网后）

设备联网后，电脑浏览器直接打开 `http://<板子IP>:8080` 即可进入管理页，**不再需要连热点**。

- 首次访问强制设置管理密码（4–64 位）；连续输错 5 次锁定 60 秒。
- 会话通过 Cookie 保持 24 小时，重启板子后失效。
- 可在管理页：修改 Wi-Fi（保存后热切换，无需重启）、修改管理密码、读取设备状态。
- 忘记管理密码时，可用热点门户（第四节）重设。

注意事项：设置门户的简易客户端只支持简单鉴权，不支持 AK/SK HMAC 签名类接口的配置。

## 六、额度来源（Agent 状态与额度）

Reporter 的额度数据源为**目录 + 注册制**，板子不感知数据源，按统一字段显示：

- **Codex**（默认）：读本地 Codex 数据库状态标记，不读日志正文。
- **火山方舟**：设置窗口"额度来源"对话框填入 AK/SK（存 `%LOCALAPPDATA%\AIAgentPanel\reporter.json`）。
- **OpenCode Go 套餐**：填 Bearer Key。
- 未知来源自动回退 Codex 显示。

5h / 周 / 月三档剩余量、重置倒计时、套餐名称均由 Reporter 上报，界面自动适配；数据源异常或过期时屏幕显示 `--` 并置"陈旧"标记。

## 七、天气页配置（和风天气）

- 需要**和风天气 API Key**（免费版即可；30 分钟刷新，约 48 次/天，免费额度 1000 次/天够用）。
- Key 通过设置门户存入板端，不进仓库。
- 位置默认自动 IP 定位；定位不理想时可在设置门户手动填城市 LocationID（缓存 24 小时）。
- 屏幕显示实时天气、3 天预报、农历、AQI、紫外线、风向与室内温湿度（板载 SHT 传感器）。
- 服务每 30 分钟刷新，失败后 60 秒重试。

## 八、日历（首页右卡）

- 自动显示当月，今天用反色块突出，**未联网校时（年 < 2020）时整块留空**。
- 返回首页时自动回到本月。
- 板面按键都被占用，**翻上一月 / 下一月只能用语音指令**（"上月 / 下月 / 今天"）。

## 九、语音行为

- 一次唤醒一轮问答：回答期间**不接受语音打断**，TTS 播完自动回待机。
- 按键主动停止仍然保留。

## 十、模拟器预览（无硬件预览 UI）

改 UI 或想先看看效果，可在电脑上跑 LVGL 模拟器（SDL2 + LVGL 9.5.0）：

- `Space` 循环页面，`P`/`S`/`W` 直跳页面，`C` 开电脑列表，`R` 循环 Agent 状态。
- 启动参数见 `simulator/README.md`，如 `AI_PANEL_START_PAGE=weather` 直接进天气页。

## 十一、常见问题

| 现象 | 排查 |
| --- | --- |
| 板子搜不到电脑 | 电脑端 Reporter 是否运行（看托盘）；两端是否同一 Wi-Fi；Windows 防火墙是否只放行"专用网络"；路由器是否开启了 AP 隔离 |
| 某些数值显示 `--` | 该项采集失败或主板不开放传感器（如部分主板的 CPU 温度区），属正常回退 |
| 只有核显时 GPU 温度是 CPU 温度 | 正常：核显与 CPU 同晶片，无独立传感器，用 CPU 温度近似 |
| Codex 状态一直"离线" | Codex 版本会影响本地日志格式；Reporter 会自动回退其他数据源，仍失败时先确认 Codex 进程在运行 |
| 屏幕整体不亮 | 第一次安装时若校验完成仍未亮，拔插 USB 并按一下开机键；不要重复刷写 |
| 管理页打不开 | 确认板子已联网（关于页能看到 IP）；地址是 `http://IP:8080`；先访问热点门户（192.168.4.1）确认 Wi-Fi 凭证有效 |

## 十二、数据与隐私

- Reporter 只开放**本机可访问**的诊断 HTTP 8765（health / status / pairing）与**局域网** UDP 8766（发现与快照），不向局域网返回明文令牌。
- 身份与配对信息保存在 `%LOCALAPPDATA%\AIAgentPanel\`（Windows）。
- 反馈问题时请提供系统版本、安装模式与错误信息；不要提交完整 Flash 备份或含凭据的行为日志。

## 十三、升级与文档

- 升级请使用安装器的"**保留配置升级**"（自动备份、只写应用分区、保留 Wi-Fi 与电脑绑定）；不要裸刷 `xiaozhi.bin` 覆盖配置分区。
- 构建细则：[构建说明](BUILD.md)；macOS 电脑端：[macOS 使用说明](../reporter/MACOS.md)；Windows 报窗说明：[Windows 窗口说明](../reporter/WINDOWS-UI.md)；发布与已知限制：[发布检查表](RELEASE_CHECKLIST.md)。
